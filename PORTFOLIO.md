# FixLab — Interactive Frontend Repair Portfolio

FixLab turns six common frontend issues into interactive before-and-after case studies. Visitors can explore responsive layout repairs, accessible navigation, CSS alignment, optimized images, form validation, and working React components—then inspect the actual implementation behind each fix.

Built with React, TypeScript, Vite, hand-written modern CSS, and Lucide, the project combines a clean responsive interface with keyboard support, reduced-motion preferences, sandboxed broken examples, and automated unit, browser, and accessibility checks.

**Project type:** Independent portfolio demonstration.

**My contribution:** Frontend architecture, interface design, implementation, responsive behavior, accessible interactions, image optimization, and testing.

**Scope:** A frontend application with browser-local demo state. No client engagement, commercial results, backend, or production deployment is claimed.
